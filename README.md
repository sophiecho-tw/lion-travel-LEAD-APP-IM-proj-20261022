# Lion Travel LEAD APP — IM Prototype

Version snapshot: 2026-10-22.

## Open the prototype

Serve this folder with any static HTTP server, then open `index.html`. No build or package installation is required.

Existing hosted preview: https://lion-lead-im-prototype.recurrence-h-3109.chatgpt.site/

## Features

- Announcements, group chats, traveler direct messages and internal company chat
- Traveler context, lodging, dietary needs and private notes
- Read receipts and explicit confirmation tracking
- Company itinerary cards and internal traveler cards
- Survey invitation cards linking to the official Lion Travel form
- Scheduled messages, translation demo and message actions

## Prototype scope

Messages, receipts, schedules and traveler records are simulated and saved in browser local storage. Translation uses preset examples. The survey button opens the external official form; completion status is not integrated.

## Files

`index.html`, `app.js`, `modules.js`, `style.css`, `modules.css`, and `assets/avatars/`.

Photo source credits are in `assets/avatars/credits.json`.
